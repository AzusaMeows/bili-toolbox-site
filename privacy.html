B站工具箱 / PRIVACY

隐私说明

适用版本：1.0.13 · 更新日期：2026 年 10 月 11 日

“B站工具箱”用于展示 B站评论中的公开性别和该条评论的 IP 属地。扩展没有开发者服务器，不使用分析、广告或追踪服务。

处理哪些信息

  • 评论用户的 UID 和公开性别：从页面已加载的评论、公开资料卡或按需查询的公开资料卡获得。仅按“男”“女”“保密”解释，不推断真实身份。
  • 评论 ID 和公开 IP 属地：只读取页面已经加载的评论字段。评论 ID 用于把属地对应到具体评论，防止同一作者不同评论串值。属地由 B站标注，不代表实时或精确所在地；没有可确认的对应关系时不显示。
  • 六项显示设置：总开关、保密/未获取显示、标记样式、自动补查、短时缓存、IP 属地显示。保存在浏览器扩展本地存储，不使用云同步。
  • 缓存到期时间：与 UID 和性别枚举一起判断是否需要再次查询。
  • 状态数量及清除通知：面板读取当前页面的昵称标记、属地标签、查询和缓存命中数量；本地保存不含个人资料的清除通知标识。

为定位昵称，扩展会临时读取用户主页链接或 UID 属性。页面原有 JSON 响应副本只提取上述字段，不保存或转发评论正文、昵称和头像。必要字段在本页脚本之间传递，以更新本页标签；这不涉及上传至开发者或其他服务。

自动补查会发送什么

“补查公开资料”默认开启。可见评论的性别缺失或为保密、且没有可用资料卡结果或缓存时，只向 https://api.bilibili.com/x/web-interface/card 发送该用户 UID。B站会按普通网络请求接收到连接 IP 等网络信息。请求不携带账号 Cookie、登录凭证、评论正文或当前页面 URL，不连接其他服务。接口不可访问时不绕过验证或访问控制。

每页最多 2 个并发查询，相邻启动至少间隔 350 毫秒；同 UID 去重，离开可见范围的排队用户会跳过。受限时暂停，失败条目短期不连续重试。关闭补查会取消主动查询。IP 属地不通过此接口补查，也不采用个人资料中的地址代替评论属地。

缓存与清理

“短时缓存”默认开启。仅将主动资料卡查询得到的 UID、性别枚举和到期时间保存在 chrome.storage.session，用于同一浏览器会话中刷新或换视频时复用。最多 1000 个用户，30 分钟后不再用于新查询；读取不延长有效期。

共享缓存位于浏览器会话内存，不写入持久存储、不云同步。关闭总功能、关闭短时缓存或点击“清除缓存”会清空共享缓存，并通知其他已打开页面。浏览器重启或扩展被停用、重新加载、更新时清空。无痕标签页不读写共享缓存。

评论 ID 和属地只在当前页面内存中使用，不进入共享缓存。旧版评论最多临时保留 2500 条对应记录；新版对应到当前评论组件，组件移除后清理。缺失字段不会借用同一作者其他评论的属地。

关闭总功能、刷新或关闭页面会清空当前页面资料。关闭“显示 IP 属地”会隐藏标签，但总功能开启时仍可能在页面内存中解析该字段，以便再次开启后显示。清除共享缓存不会删除页面当前已直接获取的数据。卸载扩展会移除设置和清除通知标识。没有服务器端副本。

共享与权限

除上述向 B站查询公开性别资料外，不向开发者或其他服务发送用户信息，不出售数据。仅申请 storage 保存设置和会话内存缓存。内容脚本只在 www.bilibili.com、t.bilibili.com、space.bilibili.com 的 HTTPS 页面运行，查询遵循 B站正常 CORS。缓存后台不联网。不申请 Cookie、浏览历史、全站访问、下载或请求拦截权限。

本网站的数据处理

本站提供产品介绍、使用说明和隐私政策，不使用统计脚本、广告、追踪 Cookie、表单或浏览器存储。访问本站时，托管服务会接收到 IP 地址、请求路径和浏览器提供的网络信息，以交付页面。扩展不会自动访问本站。

联系与变更

本扩展对用户数据的使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求，仅用于上述评论资料标记功能。不用于个性化广告、数据转售或信用评估。
