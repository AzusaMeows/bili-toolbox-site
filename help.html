B站工具箱

使用说明

在评论昵称前展示公开性别，以及 B站提供的该条评论 IP 属地。扩展独立开发，与哔哩哔哩不存在官方关联。

开始使用

  1. 扩展正在准备商店发布，正式安装入口尚未开放。开发预览版可在扩展管理页加载 extension 文件夹，并固定扩展图标。
  2. 更新后重新加载扩展，确认面板版本为 v1.0.13，再刷新 B站页面。
  3. 滚动到评论区，点击扩展图标调整显示设置。设置同步应用到本浏览器已打开的 B站页面。

性别标记

标记含义
♂ 男 / ♀ 女用户公开填写的字段
? 保密公开字段为“保密”
? 未获取暂时没有可用字段

资料不代表经过验证的真实身份。“仅符号”模式使用小图标：锁表示保密、灰点表示未获取、三点表示查询中。主评论与楼中楼都为符号保留行内位置；悬停可查看说明。

IP 属地

默认开启，显示在性别标记之后、昵称之前。只显示该条评论已经提供的字段，不额外查询；没有字段或不能确认与具体评论对应时不显示。同一作者的不同评论可以显示不同属地。标注来自 B站，不代表实时或精确所在地。

“显示 IP 属地”和“显示保密和未获取”分别控制属地及性别标记。隐藏保密性别时，已有属地仍可显示。关闭总开关会移除全部标签并清空页面数据。

自动补查与短时缓存

开启补查后，可见评论缺少可用性别时向 B站公开资料卡查询，最多 2 个并发，不携带 Cookie 或页面 URL。受限时暂停，可随时关闭。属地不通过资料卡补查。

主动查询的性别结果可在会话内存中缓存 30 分钟，最多 1000 个用户。可关闭或清除，浏览器重启或扩展重新加载后清空，无痕标签页不共享。评论 ID 和属地不进入跨页面缓存。

兼容范围

面向 Chrome 111+ 和相应 Chromium 版本的 Edge。支持 www.bilibili.com、t.bilibili.com、space.bilibili.com 上兼容的桌面评论、主评论与楼中楼，包括开放 Shadow DOM 组件和常见旧版结构。不处理移动客户端、直播聊天与普通视频弹幕。

没有显示怎么办

  • 先重新加载扩展并刷新 B站页面。
  • 确认总开关已开启，浏览器允许扩展在该站点运行，评论已加载。
  • 属地仅在 B站下发字段时出现；字段缺失不会猜测或借用其他评论的值。
  • 性别补查受限时面板会提示；网站更改页面结构后可能需要更新适配。

数据与权限

只申请 storage，用于六项设置和性别会话缓存。公开评论资料不写入持久存储，不上传到开发者或其他服务。阅读完整隐私说明。
